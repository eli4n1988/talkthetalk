# TalktheTalk

סימולטור שיחות בעברית למנהלות ומנהלי מרפאות ב**מכבי שירותי בריאות**. נכנסים לחדר אימון, **שומעים את הרופא**, מדברים בעברית, והמערכת מנתחת את הניסוח בזמן אמת.

## מה יש כאן

- שיחה קולית כברירת מחדל: הרופא פותח בקול, ואז המיקרופון נפתח אליכם
- ניתוח דיבור חי — אמפתיה, נתון, שותפות, הוראה וביקורת
- ארבע דמויות קול מעורבות: גבר/אישה, ותיק/צעיר בקריירה, כל אחד בקצב וגובה שונים
- חמישה תרחישי מרפאה מוכנים (המתנה, אנטיביוטיקה, תיעוד, תלונות הורים, מדדי איכות)
- לוח ניהול (`/admin`) לעריכת כל תרחיש ולהוספת שיחות חדשות — נשמר במכשיר זה
- נתיב הקלדה ומשפטי אימון כשאין מיקרופון
- סיכום אחרי השיחה: מה עבד / מה לנסות
- מנוע דיאלוג מקומי תמיד זמין; מפתח OpenAI אופציונלי ולא חוסם

## הרצה מקומית

```bash
npm install
npm run dev
```

השרת עולה על [http://127.0.0.1:43127](http://127.0.0.1:43127).

לחוויית קול מלאה (זיהוי דיבור + הקראת הרופא) מומלץ Chrome או Edge עם הרשאת מיקרופון.

### מפתח מודל (אופציונלי)

אין צורך במפתח. אם קיים `OPENAI_API_KEY` בסביבה, תשובות הרופא יכולות להתעדן דרך המודל; אם אין מפתח או שהקריאה נכשלת, המנוע המקומי ממשיך.

```bash
cp .env.example .env.local
```
