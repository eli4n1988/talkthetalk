# TalktheTalk

סימולטור שיחות בעברית למנהלות ומנהלי מרפאות ב**מכבי שירותי בריאות**. המנהלים מדריכים רופאי משפחה ורופאי ילדים — לעיתים מול ותק, התנגדות או עומס. האתר נותן חדר אימון: בוחרים תרחיש, מדברים עברית, והרופא המתוכנת נשאר בדמות.

## מה יש בגרסה הזו

- חמישה תרחישי מרפאה (המתנה, אנטיביוטיקה, תיעוד, תלונות הורים, מדדי איכות)
- שתי דמויות ליבה: ותיק עקשן (ד״ר מזרחי / ד״ר שפירא) ומוצף־הגנתי (ד״ר כהן / ד״ר בן־דוד)
- שיחה קולית he-IL דרך Web Speech API, עם תמליל חי
- נתיב הקלדה כשאין מיקרופון, כולל משפטי אימון מוכנים
- סיכום קצר אחרי השיחה: מה עבד / מה לנסות
- מנוע דיאלוג מקומי תמיד זמין; מפתח OpenAI אופציונלי ולא חוסם

## הרצה מקומית

```bash
npm install
npm run dev
```

השרת עולה על [http://127.0.0.1:43127](http://127.0.0.1:43127).

לחוויית קול מלאה (זיהוי דיבור + הקראה) מומלץ Chrome או Edge עם הרשאת מיקרופון. בלי מיקרופון אפשר לתרגל בהקלדה.

### מפתח מודל (אופציונלי)

אין צורך במפתח. אם קיים `OPENAI_API_KEY` בסביבה, תשובות הרופא יכולות להתעדן דרך המודל; אם אין מפתח או שהקריאה נכשלת, המנוע המקומי ממשיך.

```bash
cp .env.example .env.local
```
